# Personal Portfolio CMS

Aplikasi web portofolio pribadi modern dan profesional yang dilengkapi dengan **Admin Dashboard** mandiri untuk mengelola seluruh konten secara dinamis tanpa perlu mengubah source code.

Dibangun dengan arsitektur **React SPA (Frontend)** dan **Laravel REST API (Backend)** dengan basis data **MySQL**.

---

## Fitur Utama

### 🌟 Public Portfolio
- **Hero Section:** Profil pembuka dengan headline, typing animation profesi, tombol CV, dan link sosial.
- **About Me:** Biografi profesional dan sorotan bidang keahlian.
- **Projects Showcase:** Kartu proyek interaktif dengan filter kategori, detail proyek, link repository GitHub, dan live demo.
- **Skills & Categories:** Pengelompokan keahlian visual (Frontend, Backend, Database, Tools, Soft Skills).
- **Certificates:** Tampilan sertifikat terbit dengan link verifikasi kredensial.
- **Experience & Education:** Timeline visual riwayat pekerjaan, magang, dan pendidikan.
- **Contact Form:** Formulir pengiriman pesan langsung dengan validasi, honeypot anti-spam, dan notifikasi sukses.
- **Interactive Guided Tour:** Walkthrough interaktif langkah-demi-langkah menggunakan Driver.js.
- **Dark / Light Mode:** Dukungan tema gelap & terang dengan transisi mulus.
- **Privacy-Friendly Analytics:** Pencatatan page view anonim.

### 🛡️ Admin Dashboard
- **Admin Authentication:** Proteksi login berbasis token (Laravel Sanctum).
- **Dashboard Overview:** Statistik metrik konten dan grafik tren kunjungan (Recharts).
- **Content Management (CRUD):** Kelola Profil, Proyek, Skill, Sertifikat, Pengalaman, Pendidikan, dan Social Links.
- **Media Library:** Unggah dan kelola aset gambar serta dokumen CV PDF.
- **Message Center:** Pantau dan arsipkan pesan masuk dari formulir kontak.
- **Guided Tour Manager:** Tambah, sesuaikan, dan urutkan langkah tour publik.
- **Website & SEO Settings:** Sesuaikan title, deskripsi meta, Open Graph, dan identitas website.
